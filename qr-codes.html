HOW TO USE

Place codes around campus.

  1. Select the location from the dropdown.
  2. Download the QR code as an image.
  3. Print and display it at that location.
  4. Scan it with a phone camera. On a hosted HTTPS website, the report form opens directly with this location already selected.
Important for real deployment

For direct scan-to-form reporting, publish this website online using HTTPS first, then generate/download the QR codes from that hosted website. QR codes generated from a local file or localhost cannot open on other phones. Reports in this demo are saved only in the browser that submits them.
